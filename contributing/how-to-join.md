# 如何加入

欢迎加入 Grassroots Project！

## 加入流程

```
阅读项目 → 完成问卷 → 发送邮件 → 收到回复 → 添加到人池 → 领取任务
```

## 第一步：了解项目

在加入之前，请确保你了解：

1. **项目愿景**：为被低估的个体提供夺回定价权的协作基础
2. **核心理念**：价值不是被赋予的，是被发现的
3. **三条腿**：比特币 × 网络 × AI
4. **风险提示**：这条路没有确定的回报

推荐阅读：
- [项目介绍](../guide/introduction.md)
- [三条腿](../concepts/three-pillars.md)
- [池塘模式](../concepts/pool-model.md)

## 第二步：完成筛选问卷

回答以下问题：

### 问题 1：你是谁？

简单介绍自己：
- 年龄段
- 所在地区
- 当前状态（学生/在职/待业/自由职业等）

### 问题 2：你能贡献什么？

说明你的技能和时间：
- 技能标签（文案/设计/技术/运营/沟通/社交等）
- 每周可投入时间
- 过往经验或作品（如有）

### 问题 3：你期望获得什么？

说明你的期望：
- 为什么想加入？
- 期望从项目中获得什么？
- 短期和长期目标

### 问题 4：你对项目的理解

用自己的话说明：
- 你如何理解"三条腿"？
- 你如何理解"价值在博弈中发现"？
- 你认为这个项目的风险是什么？

## 第三步：发送邮件

将你的答案发送到：**xiaoping.tang@gmail.com**

邮件格式：
```
主题：申请加入 Grassroots Project - [你的名字/昵称]

正文：
[问题 1 的回答]
[问题 2 的回答]
[问题 3 的回答]
[问题 4 的回答]
```

## 第四步：等待回复

通常会在 1-3 天内收到回复。

回复内容可能包括：
- 欢迎加入 + 下一步指引
- 需要补充的信息
- 暂时不适合（会说明原因）

## 第五步：添加到人池

收到欢迎邮件后：

1. 访问 [人池 Issue](https://github.com/grassroots-project/tasks/issues/1)
2. 点击 "Edit"（需要 GitHub 账号）
3. 在"现有成员"部分添加你的信息：

```markdown
### [你的名字/昵称]

- **加入时间**：YYYY-MM-DD
- **技能标签**：[用逗号分隔]
- **时间承诺**：每周 Xh
- **当前任务**：无
- **历史贡献**：-
```

4. 提交 Pull Request
5. 等待合并

## 第六步：领取第一个任务

1. 访问 [任务池](https://grassroots-project.github.io/website/pages/tasks.html)
2. 登录 GitHub
3. 选择一个感兴趣的任务
4. 点击 **🙋 领取**

推荐从 P2（探索性）任务开始，熟悉流程后再挑战 P0/P1 任务。

## 常见问题

### Q：我没有 GitHub 账号怎么办？

GitHub 是必须的。去 [github.com](https://github.com) 注册一个。

### Q：我的技能不在列表里怎么办？

技能标签是灵活的，你可以添加自己的标签。

### Q：我时间不多可以加入吗？

可以。只要你能持续贡献，哪怕每周 2-3 小时也是有价值的。

### Q：我可以匿名参与吗？

可以使用昵称。但在人池中需要一个可识别的 ID。

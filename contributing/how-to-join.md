# 如何加入

欢迎加入 Grassroots Project！

## 加入流程

```
阅读项目 → 提交 GitHub Issue 申请 → 审核通过 → 自动入库 → 领取任务
```

## 第一步：了解项目

在加入之前，请确保你了解：

1. **项目愿景**：为被低估的个体提供夺回定价权的协作基础
2. **核心理念**：价值不是被赋予的，是被发现的
3. **三条腿**：比特币 × 网络 × AI
4. **风险提示**：这条路没有确定的回报

推荐阅读：
- [项目介绍](../guide/introduction.md)
- [三条腿](../concepts/three-pillars.md)
- [池塘模式](../concepts/pool-model.md)

## 第二步：提交加入申请

点击下方链接，填写 GitHub Issue 表单：

👉 [**提交加入申请**](https://github.com/grassroots-project/tasks/issues/new?template=join_request.yml)

表单内容包括：
- **昵称**
- **GitHub 用户名**
- **技能标签**（文案/设计/技术/运营/沟通/社交等）
- **时间承诺**（每周可投入时间）
- **筛选问题**（5 个关于你和项目的问题）

> 需要 GitHub 账号。没有的话去 [github.com](https://github.com) 注册一个。

## 第三步：等待审核

管理员会审核你的申请，通常 1-3 天内处理。

- 审核通过后，管理员会给 Issue 打上 `approved` 标签
- 系统自动生成 PR，将你的信息添加到人才库（`data/people.md`）
- PR 合并后你就正式加入了

## 第四步：领取第一个任务

1. 访问 [任务池](https://www.grassroots-project.app/pages/tasks.html)
2. 登录 GitHub
3. 选择一个感兴趣的任务
4. 点击 **🙋 领取**

推荐从 P2（探索性）任务开始，熟悉流程后再挑战 P0/P1 任务。

> 任务状态会自动同步到你的人才库信息，无需手动更新。

## 常见问题

### Q：我没有 GitHub 账号怎么办？

GitHub 是必须的。去 [github.com](https://github.com) 注册一个。

### Q：我的技能不在列表里怎么办？

技能标签是灵活的，你可以填写自己的标签。

### Q：我时间不多可以加入吗？

可以。只要你能持续贡献，哪怕每周 2-3 小时也是有价值的。

### Q：我可以匿名参与吗？

可以使用昵称。但需要提供 GitHub 用户名。

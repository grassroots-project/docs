# 领取任务

如何在任务池中领取和完成任务。

## 访问任务池

地址：https://www.grassroots-project.app/pages/tasks.html

## 登录 GitHub

1. 点击 **🔑 登录 GitHub**
2. 需要 GitHub Personal Access Token (PAT)
3. 获取方式：
   - 访问 https://github.com/settings/tokens/new
   - 勾选 `public_repo` 权限
   - 生成并复制 Token
4. 粘贴 Token 到登录框

Token 仅存储在你的浏览器本地，不会上传服务器。

## 查看任务

### 任务属性

- **优先级**：
  - 🔥 P0 — 必须先做
  - ⭐ P1 — 重要不紧急
  - 🔍 P2 — 探索性
  
- **状态**：
  - 📝 待领 — 等待领取
  - 🔄 进行中 — 有人在做
  - ✅ 已完成

- **技能标签**：文案、设计、技术、运营等

### 筛选任务

使用顶部的筛选按钮：
- 按优先级筛选
- 按状态筛选

## 领取任务

1. 找到感兴趣的任务
2. 点击 **🙋 领取**
3. 系统会自动：
   - 在 Issue 中添加评论
   - 将状态改为"进行中"
   - 将你设为 Assignee

## 完成任务

1. 完成工作后，点击 **✅ 完成**
2. 更新人才库中的"历史贡献"
3. 如果有产出（代码、文档等），提交到相应仓库

## 放弃任务

如果无法完成：

1. 点击 **👋 放弃**
2. 任务会重新变为"待领"状态
3. 其他人可以领取

放弃任务不是坏事，诚实评估自己的时间更重要。

## 最佳实践

1. **从 P2 开始**：新人建议先做探索性任务，熟悉流程
2. **一次一个**：专注于一个任务，完成后再领下一个
3. **及时沟通**：遇到困难及时反馈
4. **记录贡献**：完成后更新人才库信息

## 常见问题

### Q：我没看到领取按钮？

确保你已经登录 GitHub。

### Q：领取后多久需要完成？

没有硬性期限，但建议在领取时评估自己的时间。如果长时间无进展，考虑放弃让其他人领取。

### Q：我可以创建新任务吗？

可以。点击 **✨ 添加任务**，按模板填写。

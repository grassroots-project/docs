# 贡献记录

如何记录和展示你的贡献。

## 为什么要记录？

- 让贡献可追溯
- 建立个人声誉
- 为未来的价值发现做基础

## 记录位置

### 1. GitHub Issues

每个任务都是一个 Issue。完成任务时：
- 添加评论说明完成情况
- 状态会自动更新

### 2. 人才库

[人才库 Issue](https://github.com/grassroots-project/tasks/issues/1) 记录每个成员的：
- 当前任务
- 历史贡献

### 3. Git 提交历史

如果贡献涉及代码或文档，Git 历史也是贡献记录。

## 如何更新人才库

完成任务后：

1. 访问 [人才库 Issue](https://github.com/grassroots-project/tasks/issues/1)
2. 找到你的信息
3. 更新：
   - **当前任务**：移除已完成的任务
   - **历史贡献**：添加刚完成的任务

示例：

```markdown
### 小明

- **加入时间**：2026-02-08
- **技能标签**：文案、设计
- **时间承诺**：每周 5h
- **当前任务**：无
- **历史贡献**：
  - #4 [TASK] 撰写第一个钩子文案（2026-02-10）
  - #6 [TASK] 制作第一组图文笔记（2026-02-15）
```

## 贡献统计

[人才库页面](https://grassroots-project.github.io/website/pages/people.html) 会自动展示：
- 每个成员的任务数
- 进行中和已完成的任务
- 最近活动

## 最佳实践

1. **及时更新**：完成任务后立即更新
2. **保持一致**：使用统一的格式
3. **链接任务**：用 #编号 链接到任务 Issue
4. **注明日期**：记录完成日期

## 贡献的价值

目前贡献记录主要用于：
- 展示个人能力
- 建立项目声誉
- 跟踪项目进度

未来可能：
- 基于贡献的奖励分配
- 链上永久记录
- 声誉系统

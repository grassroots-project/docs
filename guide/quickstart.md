# 快速开始

5 分钟了解如何参与 Grassroots Project。

## 第一步：了解项目

浏览 [项目网站](https://www.grassroots-project.app/)，了解：

- 我们在做什么
- 三条腿是什么
- 池塘模式如何运作

或者直接和 [AI 助手](https://www.grassroots-project.app/pages/assistant.html) 对话。

## 第二步：查看任务池

访问 [任务池](https://www.grassroots-project.app/pages/tasks.html)，看看有哪些开放任务。

任务按优先级分类：
- 🔥 **P0** — 必须先做，紧急重要
- ⭐ **P1** — 重要不紧急
- 🔍 **P2** — 探索性，可以尝试

## 第三步：提交加入申请

点击 [**提交加入申请**](https://github.com/grassroots-project/tasks/issues/new?template=join_request.yml)，填写 GitHub Issue 表单。

表单内容包括：昵称、GitHub 用户名、技能标签、时间承诺，以及 5 个筛选问题。

管理员审核通过后，你的信息会自动添加到人才库。

## 第四步：领取第一个任务

加入后：

1. 去 [任务池](https://www.grassroots-project.app/pages/tasks.html)
2. 点击 **🔑 登录 GitHub**（需要 GitHub Personal Access Token）
3. 找一个感兴趣的任务，点击 **🙋 领取**
4. 开始工作！

## 第五步：任务状态自动同步

领取和完成任务后，你在人才库中的信息会自动更新：

- **当前任务**：领取时自动记录
- **历史贡献**：完成时自动归档

无需手动更新。

## 遇到问题？

- 问 [AI 助手](https://www.grassroots-project.app/pages/assistant.html)
- 查看 [常见问题](./faq.md)
- 在 GitHub 上提 Issue 讨论

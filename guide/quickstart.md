# 快速开始

5 分钟了解如何参与 Grassroots Project。

## 第一步：了解项目

浏览 [项目网站](https://grassroots-project.github.io/website/)，了解：

- 我们在做什么
- 三条腿是什么
- 池塘模式如何运作

或者直接和 [AI 助手](https://grassroots-project.github.io/website/pages/assistant.html) 对话。

## 第二步：查看任务池

访问 [任务池](https://grassroots-project.github.io/website/pages/tasks.html)，看看有哪些开放任务。

任务按优先级分类：
- 🔥 **P0** — 必须先做，紧急重要
- ⭐ **P1** — 重要不紧急
- 🔍 **P2** — 探索性，可以尝试

## 第三步：提交筛选问卷

访问 [加入我们](https://grassroots-project.github.io/website/pages/join.html)，完成筛选问卷。

问卷内容包括：
1. 你是谁？
2. 你能贡献什么？
3. 你期望获得什么？
4. 你对项目的理解

发送答案到：**xiaoping.tang@gmail.com**

## 第四步：领取第一个任务

收到回复后：

1. 去 [任务池](https://grassroots-project.github.io/website/pages/tasks.html)
2. 点击 **🔑 登录 GitHub**（需要 GitHub Personal Access Token）
3. 找一个感兴趣的任务，点击 **🙋 领取**
4. 开始工作！

## 第五步：更新人才库

完成任务后，更新你在 [人才库](https://grassroots-project.github.io/website/pages/people.html) 的信息：

- 当前任务
- 历史贡献
- 技能标签

## 遇到问题？

- 问 [AI 助手](https://grassroots-project.github.io/website/pages/assistant.html)
- 查看 [常见问题](./faq.md)
- 发邮件到 xiaoping.tang@gmail.com

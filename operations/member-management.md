# 成员管理

如何维护人池。

## 人池位置

[GitHub Issue #1](https://github.com/grassroots-project/tasks/issues/1)

## 添加新成员

新成员加入后：
1. 在人池 Issue 的"现有成员"部分添加信息
2. 使用标准模板
3. 提交 PR 或直接编辑

### 成员模板

```markdown
### [名字/昵称]

- **加入时间**：YYYY-MM-DD
- **技能标签**：[用逗号分隔]
- **时间承诺**：每周 Xh
- **当前任务**：无
- **历史贡献**：-
```

## 更新成员信息

成员应该定期更新自己的信息：
- 完成任务后更新"历史贡献"
- 领取任务后更新"当前任务"
- 技能或时间变化时更新相应字段

## 成员统计

人池页面会自动展示：
- 成员总数
- 每人的任务参与情况
- 最近活动

## 退出机制

成员可以随时退出：
- 通知项目发起人
- 可选择保留或删除人池信息
- 历史贡献记录通常保留

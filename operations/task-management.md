# 任务管理

如何创建和管理任务。

## 创建任务

1. 访问 [任务池](https://www.grassroots-project.app/pages/tasks.html)
2. 点击 **✨ 添加任务**
3. 填写 Issue 模板

### 任务模板

```markdown
## 任务描述

[描述任务目标和要求]

## 技能要求

[需要什么技能]

## 预期时间

[预计需要多少时间]

## 相关链接

[参考资料、设计稿等]

## 验收标准

[如何判断任务完成]
```

### 设置标签

- **优先级**：P0 / P1 / P2
- **状态**：待领（默认）
- **技能**：文案 / 设计 / 技术 / 运营 等

## 管理任务

### 优先级调整

根据项目需要调整任务优先级。

### 任务拆分

大任务可以拆分为多个小任务，用 Issue 链接关联。

### 关闭任务

任务完成后：
1. 确认验收标准达成
2. 将状态改为"已完成"
3. 关闭 Issue（可选）

## 最佳实践

1. **任务粒度适中**：一个任务应该能在 1-2 周内完成
2. **描述清晰**：让任何人看了都能理解要做什么
3. **有验收标准**：明确什么叫"完成"
4. **及时更新**：保持任务状态准确
